file transfer protocol  

permite subir y descargar archivos  de manera remota 
normal mente usa puerto 
en muchas ocasiones este puerto permite conexión con las credenciales  usuario anonymous  y sin contraseña

la manera de conectarse es  la siguiente :
```python
ftp {IP}
```

```python
dir
```
